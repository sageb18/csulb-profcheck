A Chrome extension that shows Rate My Professors ratings directly in MyCSULB's class search results, so you don't have to open a new tab to check who you're registering for.

---

## What it does

- Adds a small rating badge next to every instructor name in MyCSULB class search results
- Click a badge to open a card with the professor's department, overall rating, rating count, difficulty, and percent of students who'd take them again
- No matching Rate My Professors entry shows a clearly greyed-out "No data found." badge instead of guessing
- No accounts, no setup, nothing persisted beyond the current page

---

## Install (development)

1. Clone this repo
2. Go to `chrome://extensions`, enable Developer mode
3. **Load unpacked** → select the project folder
4. Visit MyCSULB, run a class search

---

## Privacy

No personal data is collected or transmitted, the only outbound request is the instructor name, sent to Rate My Professors to look up their public rating.
